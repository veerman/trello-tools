Updates Guide

How to update a board with the editor: load the last version, edit it as Markdown, check the changes, and save it to Trello as a new board.

  1. Decide what changes

    Review feedback and agree on the list of changes before anyone opens the editor.

  2. Pick one lead editor

    Only this person edits in the tool and saves and loads the Markdown file. One editor and one file is your version control.

  3. Track changes in a separate doc

    Write a short summary of each change and the reason for it.

  4. Edit the board

    • Connect to Trello (the first time, paste your Trello API key), pick the workspace, then load the previous version of the board.
    • Edit cards in Markdown: descriptions, links, checklists, attachments. Follow the format in trello-markdown-guide.md.
    • Switch views as needed: Markdown, MD/Doc, Doc, MD/Board, Board, or View on Trello.
    • Taking a break: Save to File. On the first save, rename the file for the new version.
    • Coming back: Load from File, then keep editing.

  5. Use AI for bulk changes (optional)

    • Copy a few lists at a time from the Markdown view. Small chunks keep the AI accurate and inside its context window.
    • Open Help > Modify Board Prompt, copy it, and paste it into your AI tool with the chunk and your list of changes.
    • Replace the chunk in the editor with the AI's output, then save.
    • Check that card titles and wording did not change where they should not. The check (next step) lists renamed and missing cards for you.
    • If the check finds problems, click Copy report and paste it into your AI tool with the board Markdown to have it fix them.
    • To ask questions about a board instead of changing it, use Help > Query Board Prompt.

  6. Review

    • Click the check summary next to the Editor heading (it also opens when you click Save to Trello). It lists: problems that would stop the save, warnings about content that would be ignored, and changes compared with the board you started from: removed, renamed, new, and moved cards, removed attachments, and fewer checklist items.
    • The original is the board you loaded from Trello. If you started from a file, it is the first file you loaded. To compare with a different file, use Use a different original... in the check.
    • For a line-by-line view, open Help > Compare Markdown and load the previous file and the new one. Make sure links and attachments work.

  7. Publish

    • Name the file for the new version and load the final file.
    • Click Save to Trello. This creates a new board in the chosen workspace.
    • Check that file attachments on the new board open for the people who need them.
    • Share the new board with the people who need it.

Why Markdown: its plain text structure shows the board's hierarchy clearly to both people and AI tools, so updates are faster and have fewer errors than editing cards one by one in Trello.
